How it works

NCM captures a pre-snapshot before the change window opens and a post-snapshot after it closes. The config diff is pulled via REST API and fed to the LLM engine for comparison against the CR spec.

ServiceNow — Integration

Connection Status

✓ ConnectedTable APIRead + Write
Instance: company.service-now.com · Table: change_request · Trigger: CR state → Review

What gets pulled

When CR state moves to Review, the Table API pulls CR fields — source IP, destination, port, zone, action, logging requirements, and implementation steps. This becomes the authoritative approved spec.

What gets written back

After LLM analysis, the drift verdict is written back as a CR work note. If drift is detected, a remediation CR is raised automatically.
